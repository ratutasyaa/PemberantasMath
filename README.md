# PemberantasMath
Cryptic-Quest adalah website game petualangan interaktif yang mengajak pemain berperan sebagai Detektif Siber atau Arkeolog Digital untuk menyelesaikan misi dan mengungkap misteri. Pemain harus memecahkan berbagai teka-teki matematika, logika, dan kriptografi yang ditemukan sepanjang permainan untuk menyelesaikan setiap tantangan.
